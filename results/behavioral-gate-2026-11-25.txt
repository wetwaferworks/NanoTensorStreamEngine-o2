THE BLOCKER, stated plainly
The gate as specified (pack Sigma at PQ d8 K256 RMS and PQ d4
K256 RMS with the shipped quantizer, run nq2-logitcmp raw vs
each pack) cannot run as specified. The shipped quantizer
(nq2-quantize) writes block-VQ packs; PQ exists in the tree
only as nq2-pq, a per-tensor measurement probe that writes no
pack. No shipped tool produces an engine-readable PQ pack,
and producing one is a pack-format change, which waits for
JD's explicit format call (same decision bucket as H3b and
format v3). The PQ behavioral rows are therefore empty in
this record, on purpose, until that call.

What this file records instead:
(1) the PQ weight-space curve, measured fresh with nq2-pq
    (RMS frame) on four representative Sigma tensors;
(2) a true behavioral curve at the rates the shipped format
    has: lab-engine logits, raw vs the frozen baseline pack,
    compared with nq2-logitcmp (post-M7: strict by default).

(3) PROBES (writer-side, format-preserving)

Probe A: per-tensor books vs one global book, identical
tensor set (Sigma layer 0: q/k/v/o/gate/up/down, 7 tensors,
116,391,936 weights, block 256, quantizer-reported):
  global book:      rel L2 0.9865, complete 0.1743 bpw
  per-tensor books: rel L2 0.9729, complete 0.2824 bpw
Per-tensor books buy 1.4 points of rel L2 for +62% complete
rate on this set; the book overhead (7 x 256 KB) dominates
at this scale and amortizes on larger models, but at block
256 both settings are near-total-loss per tensor. Verdict:
a real but small lever; already available as the shipped
--books per-tensor option; NOT adopted as a default change.

Probe B: the embedding under its own book vs the shared
book. Own-book pack of embed_tokens alone: rel L2 0.9807.
The same tensor inside the frozen global-book pack
(errprobe): rel L2 0.9885. Same story at smaller scale:
book granularity is worth about a point, not a regime.

Probe C: where the error actually sits (errprobe --all on
the frozen pack): the top 10 of 241 packed tensors hold
54.6% of the squared error; the median per-tensor rel L2
is 0.9943 while the aggregate is 0.6922, carried by a few
large well-fit tensors. Sensitivity weighting that would
matter is per-tensor BIT budgets (smaller blocks for the
worst tensors). That is not expressible in the current
format: block size is a pack-global header field. STOPPED
at the format boundary and flagged for JD with H3b and
format v3. The scripted approximation available today is
separate per-scope packs at different block sizes via
--filter + --block, at the cost of one stream per scope.

Bottom line of phase 2: the shipped format's levers are
measured and small; the lever that changes the regime is
PQ (section 1), and PQ needs the format call.
