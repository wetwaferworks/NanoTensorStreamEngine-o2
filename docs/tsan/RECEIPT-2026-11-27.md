## How to rerun

From the repository root, on Linux or WSL, with gcc and libtsan:

    ./docs/tsan/run-tsan.sh

The script builds with `-O1 -g -std=c99 -pthread -fsanitize=thread` and
sets `TSAN_OPTIONS=halt_on_error=1:abort_on_error=0:report_bugs=1:exitcode=66`.
Binaries and raw logs go to `build/lanes/tsan/` (gitignored).

On Ubuntu 24.04 and WSL the default `vm.mmap_rnd_bits=32` places mappings
inside TSan's reserved range (`FATAL: ThreadSanitizer: unexpected memory
mapping`). The runner re-executes itself under `setarch $(uname -m) -R`
so address-space randomization is off for that process tree only. It
does not change the system sysctl. If `setarch` is missing, lower
`vm.mmap_rnd_bits` to 28 and rerun.

There is no ThreadSanitizer on MinGW-w64 Windows. clang is not required;
this receipt used gcc 13.3.0.
